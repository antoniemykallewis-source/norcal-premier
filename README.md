# NorCal Premier: Game Day Hub

A parent-first website concept by Vessel Archive. Prepared October 13, 2026.

## Use on GitHub Pages

The site files are at the repository root. GitHub Pages publishes from `main`, `/(root)`. All paths are relative, so the site works under a GitHub Pages project path. No build, package manager, API keys or backend required.

## Included

- Responsive homepage with a custom procedural 3D soccer ball, drawn with Canvas.
- Competition selector for seven NorCal programs.
- Everything-you-need hub, resource search and seven task tabs.
- Official schedules, results, field maps, brackets, rules and app links.
- Optional local competition preference and check-in checklist.
- Keyboard tab navigation, reduced-motion support, pause control, FAQ and mobile quick navigation.
- Sources page documenting scope and current-content boundaries.

## Content and launch

This is an independent concept, not an official NorCal site. The concept monogram should be replaced with NorCal-approved logo assets in production. Competition dates are a dated snapshot and explicitly distinguish schedule release dates from match dates. No invented live results, teams, venues or scores are displayed.

The website currently links to the official NorCal app, GotSport and AthleteOne. Integrated scores, live brackets and event-level alerts would require approved data access. Do not scrape private team data or create a competing source of truth. Production scope needs CMS/content ownership, migration redirects, link monitoring, accessibility review and real-device performance testing.

Font files carry over from the user's approved Vessel/HMCI design reference. Archivo, Instrument Serif and Martian Mono are open-source Google Fonts. No third-party JavaScript, video embeds or image downloads are needed at runtime.

## Verification

JavaScript syntax, source links, DOM interactions, local persistence, keyboard behavior and the 3D model's face count are checked locally. Browser screenshot and Lighthouse verification are subject to the browser tools available in the workspace; do not present a predicted Lighthouse score as measured.
